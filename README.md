# Hopper for Android

This is Hopper's official GitHub download repository, not the Android application source. No public APK is available here until a release has passed its checks and been approved. Do not install APKs offered by other accounts or links.

When a release is published, download its universal APK and matching SHA-256 checksum from the [Releases page](https://github.com/hopper-social/hopper/releases). Check the checksum before installation. A matching checksum detects changes to the download; it does not prove who published it. Android can preserve data on an in-place update only when the package and signing certificate match. Do not uninstall an existing installation to bypass an update error.

Read Hopper's [privacy information](https://hopper-social.github.io/hopper-legal-pages/privacy.html) and [account-data deletion limits](https://hopper-social.github.io/hopper-legal-pages/deletion.html). Nearby messaging requires another reachable Hopper user and compatible device radios; offline communication is not guaranteed.

GitHub's automatic "Source code" archives for this repository contain only the download repository, not the Android app source.
